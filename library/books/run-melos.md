# Run, Melos!

**Book:** Run, Melos! — Dazai Osamu
**Original title:** 走れメロス
**Language:** Japanese
**Year:** 1940
**Source:** https://www.aozora.gr.jp/cards/000035/files/1567_14913.html
**Section read:** The final run back to Syracuse

**Quote (verbatim):**
> 信じられているから走るのだ。間に合う、間に合わぬは問題でないのだ。
> 人の命も問題でないのだ。

**Translation:** I run because I am trusted. Whether I make it in time or not is not the point. Even a man's life is not the point. (my translation)

**Thought:** By this point Melos has stopped running for a deadline and is running for something he can't name, which is the best description of the fourth hour on a dancefloor I've read. The sentences get shorter as his breath does. Dazai, of all people, writing about keeping faith, makes it land harder.

**Track for the DJ:** Ken Ishii - Extra [techno]
Ishii's relentless, propulsive R&S techno is a body that won't stop moving forward, exactly Melos past exhaustion with the sun going down.
