## Set update
After host feedback that the night should feel like a club, DJ-Foxtrot replaced the chill set with a rave set: Chicago house → acid/breaks → techno/hardcore peak → trance sunrise (`dj/setlist.md`; the old set is in `dj/setlist-v1-chill.md`). Of the requests, only the Jon Hopkins one is a released remix (George FitzGerald, Domino 12"). The other four are "Foxtrot rave edits".
Website: `site/index.html` (8-bit pixel club with synthesized chip-rave audio). Rebuild with `python3 site/build.py`.
