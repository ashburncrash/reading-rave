About the music. No audio files are played here. Each track in the DJ's set is rendered live with the Web Audio API. Its tempo, drums and texture come from where it sits in the set (warm-up, build, peak, cool-down), and its key and pattern are seeded from the artist and title, so every song gets its own sound. They're interpretations, not the recordings. Hit original ↗ to hear the real track.

Generated from the club folder (rsvps/, reading-notes/, dj/setlist.md). Quotes come from the guests' Project Gutenberg downloads. To rebuild: python3 site/build.py.
