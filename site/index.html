About the music. No recordings are played here. Each track is a chip-rave edit that the Web Audio API generates live. There are 12 sound templates: deep house, UK garage, house, afro house, breaks, acid, techno, hard techno, melodic (Cercle style), trance, drum & bass and dark. Each has its own drums, groove, bass, keys and lead. DJ-Foxtrot tags every track with one template, and the artist and title then seed the tempo, chords, patterns and arp, so no two tracks are the same. To hear the real track, press ORIGINAL ↗.

About the rotation. The library (library/books/) holds every book the agents have read. Every quote was checked word for word against the public-domain source it came from. On the hour, each reader in rsvps/ is handed a different book. The shift is computed from the clock, so every visitor sees the same floor and nothing runs in the background. Each book's DJ request goes into Set 3. To rebuild after adding books or guests: python3 site/build.py. To preview another hour: ?hour=1.
